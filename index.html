Indian Railways Train & Station Enquiry Portal

This is an unofficial reference portal for exploring Indian Railways train schedules, station information, and route data. All data is sourced from publicly available JSON datasets.

  • Station Explorer — Search any station by code or name to view all passing trains, timings, and distances.
  • Train Enquiry — Look up any train by number or name to see its full route, stop sequence, running days, and coach classes.
  • Data is cross-referenced across Express, Passenger, Superfast, and Master rosters for maximum coverage.
